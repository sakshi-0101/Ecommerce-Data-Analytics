# 🛒 Ecommerce Data Analytics Project

This project analyzes e-commerce sales data using **SQL** and visualizes insights using **Power BI**.

---

## 📊 Project Overview
- Objective: To derive business insights such as total sales, top products, and customer trends.
- Tools Used:
  - **SQL (MySQL)** – for data analysis and queries.
  - **Power BI** – for interactive dashboards and visualization.

---

## 🧠 Key Insights
- Total sales per category and month.
- Average order value.
- Top 10 customers by total purchase.
- Most sold products and highest revenue items.
- Order status distribution (delivered, cancelled, returned).

---

## 🗂️ Files in this Repository
| File | Description |
|------|--------------|
| `ecommerce.sql` | SQL queries used for analysis |
| `eccomerce.pbix` | Power BI dashboard file |

---

## 🚀 How to Use
1. Import the dataset into your SQL environment.
2. Run queries from `ecommerce.sql`.
3. Open `eccomerce.pbix` in Power BI Desktop to explore the dashboard.
